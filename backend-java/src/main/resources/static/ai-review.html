지원 형식은 UTF-8 CSV입니다. 업무 내역은 아래 예제 양식, 은행 내역은 기본 양식 또는 우리은행 거래내역 양식을 사용하세요. 다른 양식은 등록 전에 열 구성을 맞춰야 합니다.
