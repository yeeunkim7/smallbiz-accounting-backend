CSV 업로드

업무 CSV와 은행 CSV는 헤더와 저장 규칙이 다릅니다. 화면의 안내는 편의를 위한 것이고, 최종 결과는 서버 응답입니다.

업무 CSV

경로 POST /api/v1/uploads/business, 필드 이름 file. UTF-8, 필수 헤더: vendor_code, event_type, usage_date, expected_cash_date, amount, note, source_line_id.

등록된 거래처 코드가 필요합니다. event_type은 CHARGE_EXPECTED, SETTLEMENT_EXPECTED, REFUND_EXPECTED, USAGE입니다. 날짜는 YYYY-MM-DD, 금액은 콤마 없는 원화 정수입니다. 본문 5MiB, 데이터 행 10,000개까지입니다.

은행 CSV

경로 POST /api/v1/uploads/bank, 필드 이름 file. UTF-8, 필수 헤더: booked_date, direction, amount, counterparty_name, description, source_line_id.

거래처와 자동으로 연결하지 않습니다. direction은 IN 또는 OUT입니다. 날짜·금액 규칙은 업무 CSV와 같습니다. 본문 5MiB, 데이터 행 10,000개까지입니다.
