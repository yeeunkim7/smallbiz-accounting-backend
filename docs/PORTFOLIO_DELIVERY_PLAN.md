# 포트폴리오 우선 개발 방향

2026-11-01 사용자 방향 변경을 반영한다. 기존 백엔드·Expo 코어는 보존하고 `청구 등록 → 입금 등록 → 근거 검토 → 부분/묶음 연결 확정 → 서버 미수 감소 → 사유 있는 취소·복구`를 실제로 시연하는 일을 우선한다.

1. 현재 기능4b에서 모바일 후보 검토·확정·취소를 기존 Java 트랜잭션 API에 연결하고 브라우저로 검증한다. AI나 기기 계산으로 잔액을 확정하지 않는다.
2. 완료된 흐름의 합성 데이터 시나리오, ERD·API·동시성/재전송/감사 이력 설명, 실행 근거를 포트폴리오로 정리한다. 시연 영상은 흐름 완성 후 별도 작업으로 녹화하며, 브라우저 모바일 화면과 실제 iPhone/토스 앱 녹화를 구분한다.
3. 앱인토스 서비스 적합성·현재 SDK/정책을 확인한 뒤 클라이언트 적용 범위를 정한다. Java API·타입·검증·표시 로직은 재사용 후보이며 Expo 앱의 그대로 업로드를 전제하지 않는다. 토스 로그인은 은행 거래 조회 권한을 의미하지 않는다.

모바일 CSV, PRO AI, 실제 유료 구독, iOS/Android 스토어 출시는 후순위다. 계정·금융 자료의 공개 운영 보안과 개인정보 정책은 실제 출시 전 별도로 검증한다. 외부 공개 배포·유료 서비스·스토어 제출은 사용자 명시 지시 없이 수행하지 않는다.
