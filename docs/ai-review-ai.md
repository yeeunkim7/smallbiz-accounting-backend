# 읽기 전용 AI 검토 연결

> 문서 범위: 기존 AI 연결의 구현·검증 이력이다. 현재 서버는 tenant 전용 조회 도구가 없어 PRO를 포함한 모델 실행을 차단한다. 키 존재 여부·검증 수치는 당시 환경 기록이며 실제 모델 호출 검증을 뜻하지 않는다. [현재 보안 경계](AUTH_FOUNDATION.md)

갱신: 2026-10-31 (Asia/Seoul). 최신 게시 환경의 기존 구현을 확인한 뒤 중단된 개발을 이어갔다. 이전 환경의 파일을 다시 적용하지 않았다.

## 모델 요청·재시도 한도

- 검토 한 번당 모델 API 요청은 **최대 5회**다. `AiReviewService.MAX_MODEL_REQUESTS`가 모든 `AiCompletionClient.complete` 호출을 감싸는 단일 반복문의 상한이다.
- 근거 도구를 충분히 호출하지 않아 다시 요청하는 경우도 같은 5회 예산을 사용한다. 여섯 번째 요청은 정상 답변이 가능하더라도 보내지 않는다.
- 다섯 번째 응답이 유효하면 검토를 반환할 수 있다. 그때까지 완료하지 못하면 `AI_REVIEW_LIMIT` 오류로 종료하며 임의의 성공 답변을 만들지 않는다.
- API 공급자 오류를 자동 재시도하지 않는다. 인증·요청 제한·전송 실패는 안전한 오류로 반환한다. 무한 반복·무한 재시도는 없다.
- 모델 요청 수와 조회 도구 호출 수는 별개다. 조회 도구 호출은 검토당 최대 16회이며, 서버의 동시 검토는 2건으로 제한한다. 이 한도들은 금액 기준 결제 한도가 아니다.

## 읽기 전용·근거 계약

모델에 노출하는 도구는 `get_daily_summary`, `list_business_originals`, `list_bank_originals`, `list_related_uploads` 네 개뿐이다. 도구 인자는 요청한 날짜와 허용된 페이지·방향 조건으로 검증한다. 임의 SQL, HTTP 주소, 거래 수정, 업로드, 검토 완료 저장 도구는 제공하지 않는다.

금액 사실은 기존 Java 요약 결과로 생성한다. 모델이 생성한 금액 사실을 채택하지 않으며, 입금·출금 및 자료 없음·합계 일치·개별 매칭 미평가를 구분한다. 가능한 원인과 추가 확인 사항은 모델의 해석이며 조회된 근거 ID만 인용할 수 있다. ID가 실제 존재한다는 검증이 문장의 의미적 정확성을 보장하지는 않는다.

원본 메모·파일명은 신뢰할 수 없는 참고 텍스트로 전달한다. 조회된 원본이 없다는 이유로 파일 미업로드를 단정하지 않는다. 일부 페이지만 읽으면 부분 조회임을 결과에 표시한다. 완료 직전 요약이 바뀌면 `AI_DATA_CHANGED`로 다시 조회하도록 한다.

## 키·전송·오류

`AI_API_KEY`는 서버의 비밀 설정에서만 읽는다. 코드·저장소·브라우저·로그·문서에 실제 키 값을 넣지 않는다. API 목적지는 고정 HTTPS 주소이며 TLS 검증을 유지한다. 코드의 모델 이름 기본값은 `gpt-4.1-mini`다. 현재 게시 환경은 `AI_MODEL` 설정으로 이를 재정의하며 총괄이 기동한 검증 앱에서 `gpt-6-luna`가 반환됐다. 사용자 설정은 덮어쓰지 않았다. 해당 모델의 실제 공급자 지원·접근 권한·요금은 검증하지 않았다.

기존에 적용된 전송 보호도 유지했다: 본문 수신 중 1MiB 초과 취소, 전체 본문 수신을 포함한 35초 제한, 중단 시 비동기 요청 취소. 공급자 응답 원문과 비밀값을 사용자 오류에 포함하지 않는다. 명시적인 `null` 도구 인자는 실행 전에 거부한다.

총괄이 현재 환경에서 키 변수의 존재를 확인했지만, 이는 인증·모델 접근·결제 설정 성공을 뜻하지 않는다. 사용자의 ChatGPT 에이전트 한도 복원은 유료 모델 API 호출 승인이 아니다. **실제 모델 호출은 비용 승인 전까지 보류하며 이번 재개 작업에서도 수행하지 않았다.**

## 이번 검증

실행 명령:

```bash
source /workspace/.local/env.sh
cd /workspace/smallbiz-accounting-backend/backend-java
bash gradlew --offline --no-daemon \
  --project-cache-dir /workspace/.local/gradle-ai-resumed \
  test --tests 'com.smallbiz.reconciliation.aireview.ai.*' --rerun-tasks
```

결과: **24개 성공**, 실패·오류·스킵 0. `AiReviewServiceTest` 15개, `OpenAiCompletionClientTest` 9개. `BUILD SUCCESSFUL`, 종료 코드 0. 두 테스트 클래스는 가짜 모델과 모의 HTTP 클라이언트를 사용하므로 실제 유료 API를 호출하지 않는다. PostgreSQL 데이터 변경도 없다.

이번 경계 검증은 여섯 번째 응답을 가짜 클라이언트 큐에 남겨 두고 불완전 근거 재요청·반복 도구 요청이 모두 다섯 번에서 중단되는지 확인한다. 반대로 다섯 번째 응답의 정상 완료도 검증했다. 공급자 오류에서 호출 한 번 후 즉시 종료하는 검증을 보강했다.

실제 모델의 도구 선택, 한국어 해석, 근거의 의미적 타당성, 지연과 비용은 별도 승인 후 평가해야 한다. 자동 테스트 통과를 실제 모델 검증으로 표시하지 않는다.
