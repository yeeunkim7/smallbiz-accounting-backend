# AI 검토 — 독립 검토와 수정 기록

> 문서 범위: 기존 AI 기능 단계의 독립 검토 기록이다. 당시 미구현으로 언급된 인증은 이후 [계정·사업체 경계](AUTH_FOUNDATION.md)에서 추가됐다. 아래 테스트 날짜·실행 주체·모의 응답 검증 범위를 보존한다.

최종 확인일: **2026-11-01 (Asia/Seoul)**. 초기 구현과 다른 `independent_review_nov01`이 최신 환경의 query/AI/frontend 코드를 다시 검토하고 독립 Chromium 회귀 검증 3개를 직접 수행했다. 실제 유료 모델 API는 호출하지 않았다.

아래 초기 기록은 2026-10-31의 검토·총괄 검증 이력이다. 당시 실행 한도로 미완료였던 독립 재검토는 이번에 재개했으며, 최신 범위와 결과는 문서 하단에 별도로 기록한다.

## 전달받은 발견 사항과 처리

| 발견 | 처리 | 검증 |
| --- | --- | --- |
| `null` 도구 인자를 허용한 뒤 `Map.copyOf(args)`에서 NPE가 나면 안전한 AI 오류가 아닌 500 발생 | 명시적인 null 인자를 도구 실행 전에 거부 | `AiReviewServiceTest.rejectsExplicitNullArgumentsWithoutLeakingNullPointerFailure` |

조회 코드에서 기존 Java 금액 재사용, 서비스 인자 검증, 관련 업로드 독립쿼리, 읽기 트랜잭션은 초기 검토 시 중대 결함이 발견되지 않았다. 이는 모든 상황의 무결성을 보장하는 인증을 뜻하지 않는다.

## 총괄 후속 검증

- 기존 56개와 신규 30개 전체 테스트, 실패/오류/스킵 여부를 XML로 확인.
- canonical Java 금액 문장의 천 단위·음수 표기 일관성 정리. 모델이 임의로 만든 금액 사실은 응답에 채택하지 않음.
- 실제 Chromium에서 날짜·요약·입출금 원본 필터·원본 근거·관련 업로드·키보드 탭·모바일 390px 확인.
- 명시적 UI 고정 응답으로 AI 결과/근거 이동, HTML 문자열 텍스트 처리, 오류/재시도, 날짜 변경 경합을 확인. 실제 모델 호출 성공으로 대체하지 않음.
- 작은 본문/상태 글씨와 터치 영역을 조정하고 화면을 재촬영.
- 최종 결제·실제 모델 호출은 요청자가 비용 확인 중이므로 보류.

## 남은 위험·한계

- 실제 모델의 도구 선택·한국어 추론·인용의 의미적 근거는 아직 미검증. ID 허용 목록은 근거가 실제 조회됐음을 검증하지만 문장이 그 근거로 정당화되는지까지 증명하지 않는다.
- 요약 재조회 변경 감지는 금액·건수·검토상태 기준. 앞으로 동일 합계·건수의 원본 수정 기능이 생기면 원본 버전/스냅샷 검증을 추가해야 한다.
- 인증·기업/계좌별 권한·운영 요청 제한·개인정보 및 외부 AI 전송 정책을 갖추기 전 공개 운영하면 안 된다. 이번 검증은 격리된 로컬 개발 범위다.


## 2026-11-01 독립 최종 재검토

최신 실행 환경 ID가 `ccarenv…c4cd45a9…`와 일치함을 확인하고 현재 파일을 읽었다. 이전 환경에서 수행한 검증을 이번 환경의 결과로 대신하지 않았다. 기능 코드와 테스트는 직접 수정하지 않았고 발견 사항을 UX 담당 및 총괄에게 전달했다.

### 검토한 계약

- `AiReviewService.MAX_MODEL_REQUESTS=5`를 모든 `AiCompletionClient.complete` 호출을 감싸는 유일한 루프에서 확인했다. 불완전한 도구 사용을 보완하는 재요청도 같은 예산을 쓰며, 공급자 오류에는 별도 자동 재시도 루프가 없다.
- `AiReviewServiceTest`의 여섯 번째 요청 미실행(불완전 근거/반복 도구)과 다섯 번째 응답 정상 완료 경계 테스트를 확인했다. 이 테스트들은 가짜 모델을 사용한다.
- 모델에는 네 가지 조회 도구만 노출한다. 서비스가 날짜·방향·페이지·허용 인자를 검증하고, 응답의 근거 ID는 실제 조회된 허용 목록으로 확인한다. 거래 수정·업로드·검토 완료 저장 도구는 없다.
- 금액 사실은 기존 Java 요약에서 생성하며 모델의 금액 서술은 채택하지 않는다. 방향별 자료 존재, 합계 상태, 개별 매칭 미평가를 별도로 전달한다.
- 원본 범위와 관련 업로드는 준비된 SQL 인자를 사용하고, 관련 업로드를 원본 한 페이지에서 추출하지 않는다. 조회 트랜잭션은 읽기 전용이다.
- 서버 비밀 설정으로 키를 읽고 API 목적지는 고정 HTTPS 주소다. `build.gradle`의 테스트 JVM은 `AI_API_KEY`를 빈 값으로 재정의해 호스트의 실제 키를 상속하지 않으며, 모의 HTTP/모델 테스트는 그대로 유지한다.
- 기존 명시적 null 거부, 본문 1MiB 제한, 전체 본문 제한시간·취소 보호가 유지된 것을 확인했다.

### UX 발견 사항과 수정 재검토

| 발견 | 현재 처리 | 독립 검증 |
| --- | --- | --- |
| 날짜 변경이 서버 모델 작업·비용까지 취소하는 것처럼 안내 | 이전 결과를 표시하지 않으며 이미 요청한 검토는 계속 처리될 수 있다고 수정 | 코드·문구 확인 |
| 날짜 변경 시 기존 REVIEWED/NEEDS_RECHECK 색상 클래스 유지 | 텍스트와 클래스를 함께 `status neutral`로 초기화 | Chromium에서 REVIEWED → 날짜 변경 후 neutral 직접 확인 |
| 모바일에서 유형 열이 숨겨져 원본의 입출금·업무 유형을 확인하기 어려움 | 원본 상세에도 유형 표시 | 현재 원본 상세 생성 코드 확인; 전체 모바일 검증은 UX 담당 결과와 구분 |
| 최초 화면 요약 T0와 더 최신 AI 응답의 Java 요약 T1이 달라질 수 있음 | 응답 요약의 날짜/형태 확인 → 상단 요약 반영 → 원본·업로드 재조회 → AI 결과 표시 | 별도 고정 응답 T1(예정 90,000원/실제 80,000원/차이 −10,000원)으로 상단·검토 상태·재조회 확인 |
| AI_DATA_CHANGED를 일반 AI 재시도로 안내 | AI 버튼을 잠그고 하루 재조회 경로 제공 | 409 고정 응답 → 버튼 비활성 → 하루 재조회 후 활성 직접 확인 |

독립 브라우저 스크립트는 `/tmp/independent-review-ui.py`, 실행 로그는 `/workspace/.local/run/nov01-independent-ui.log`다. **3개 모두 통과**했으며 모든 `/api/v1/ai-review/**` 요청을 가로챘다. 이는 실제 Chromium에서의 UI 검증이지만 실제 모델 도구 호출이나 DB 저장·조회 결과의 재검증은 아니다. 전체 DB 통합·회귀 테스트 결과는 총괄의 별도 실행 결과와 구분한다.

현재까지 이 검토 범위에서 수정하지 않은 P1/P2 코드 결함은 발견하지 않았다. 사용자·회사별 권한과 외부 전송 정책 등 공개 운영 조건은 이번 로컬 기능 검토의 완료 판정에 포함하지 않는다. 실제 모델의 한국어 해석·인용 의미·지연·요금은 비용 승인 후 별도 검증해야 하며, 근거 ID 존재 검증을 의미적 정확성 보장으로 해석하면 안 된다.
